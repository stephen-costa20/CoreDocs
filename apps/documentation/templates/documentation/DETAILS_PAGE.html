Overview

This page defines the visual and interaction patterns used across the product suite. It’s a practical guide to colors, spacing, typography, and code examples you can copy/paste directly into your app.

Info

Use a predominantly white background with restrained blue accents to keep interfaces legible and professional.

Warning

Avoid using more than two saturation levels of blue on a single screen—overuse reduces focus and perceived hierarchy.

Tip

Use myfin-50/100 for subtle surfaces and myfin-600/700 for emphasis and primary actions.

Typography

We use system fonts with Roboto preference for clean legibility. Maintain a clear hierarchy—large, bold headings; medium subheads; and body text at 14–16px line-height ~1.5.

Scale

  • H1 – 28–36px
  • H2 – 20–24px
  • H3 – 16–18px
  • Body – 14–16px

Color

The palette is centered on trustworthy blues with occasional teal/indigo accents. Keep content areas white, use dividers for structure, and apply blue sparingly for CTAs and links.

  <button class="rounded-full bg-myfin-50 text-myfin-700 hover:bg-myfin-100 px-4 py-2">Pill</button>

Form Field

<label class="block text-sm text-slate-700 mb-1" for="email">Email</label>
  <input id="email" type="email" placeholder="you@company.com"
  class="w-full rounded-md border border-slate-300 bg-white px-3 py-2 text-slate-800 shadow-soft focus:border-myfin-500 focus:ring-2 focus:ring-myfin-200 outline-none" />

Tables

Use lightweight borders and generous cell padding for scannability.

Token Value Usage
myfin-50 #F5FAFF Subtle surfaces
myfin-600 #1E88E5 Primary action

Code Examples

Copy-ready examples you can drop into your app:

/* Toggle a class on scroll for a compact header */
  const header = document.querySelector('header');
  window.addEventListener('scroll', () => {
    header.classList.toggle('shadow', window.scrollY > 8);
  });
